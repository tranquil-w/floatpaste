LOGO EXPLORATION · PHASE 2

FloatPaste · 浮贴 — 6 个图形方向

产品内核：全局快捷键唤起速贴面板 → 挑选历史条目 → 无打断回贴。 本轮 6 个方案按不同图案类型生成（纯几何 / 符号 / 聚焦框 / 浮层线条 / 胶囊流 / 节点网络）， 全部避开已否决的记事本、字母与双色块方向。每张卡片含品牌底、浅色、深色与 16/32px 小尺寸效果。

PURE GEOMETRIC

V1 一贴即中

寓意：内容从剪贴板「贴入」当前输入位——箭头落入槽位，粘贴动作的最直接抽象。笔画 8 单位，全圆端点。

风险：远看略近「下载」类图标，靠槽位的圆角短棒做区分。

GEOMETRY + SYMBOL

V2 速贴键帽

寓意：整个产品的核心交互是一颗全局快捷键——键帽 + 闪电，速度感与热键心智合体。

优势：叙事最贴产品；闪电符号常见，靠键帽语境建立差异。

GEOMETRIC · RETICLE

V3 光标聚焦

寓意：聚焦框锁定光标位置，圆点「落贴」——精准、无打断地贴到光标处。落点刻意下移 1 单位制造落定张力。

优势：辨识度高、16px 极稳；语言偏「工具/精确」，气质冷静。

GEOMETRY + MOTION LINES

V4 浮层升起

寓意：速贴面板「浮」在任何工作之上——实心面板 + 两道悬浮波，名字里的 Float 直译成图形。

优势：与产品名强绑定；悬浮波在 16px 会简化成一条弧，需小尺寸专用稿。

DOT MATRIX · CAPSULES

V5 胶囊流

寓意：历史条目沿轨迹加速飞行、汇入落点——「从历史到光标」的速度感。胶囊沿切线旋转，动能自左下指向右上。

风险：16px 下只剩斜向虚线，动势在、语义弱。

NODE NETWORK

V6 节点汇入

寓意：多条历史（左列大小节点）经由曲线汇入唯一落点（右实心大节点）——多选一的粘贴决策瞬间。

优势：叙事完整；节点网络图形在效率工具里不常见，差异化好。

ROUND 2 · FLOAT PANEL FAMILY

浮层系延伸 — V4 方向的 5 种「浮」法

统一气质：实心圆润面板、无内部线条；差异只在表达「浮」的语言——波、影、轨迹、尾巴、渐隐、倾斜。

BASELINE

V4 原型 · 悬浮波

浮 = 两道悬浮波。面板与波之间的大间隙制造高度，波是「悬浮力场」。

SHADOW DOCK

V7 影托

浮 = 大间距 + 地面影。元素最少（仅 2 个），扁椭圆是「地面」，间距即悬浮高度。最极简的一版。

LIFT TRAIL

V8 升起轨迹

浮 = 刚弹出的瞬间。两道斜向运动线记录面板「从输入位弹起」的路径，定格快捷键按下后的那 100ms。动势最强。

TOOLTIP TIP

V9 气泡尾巴

浮 = 指向输入位的尾巴。tooltip 是「悬浮在你工作上方的小窗」的原生符号，尾巴指向当前光标。单连通轮廓，小尺寸最整。

FADE LADDER

V10 浮梯残影

浮 = 渐隐的历史序列。面板下方两道递减圆角条是「上浮时留下的旧条目」——剪贴板历史的层叠感，但不做成复制图标。

TILT + SPARK

V11 微倾 + 光点

浮 = 轻、随手一贴。-7° 微倾打破呆板，右上角四角光点是「轻盈闪现」。六案中气质最活泼。

ROUND 3 · SOFT TEXTURE · FLOAT PANEL

质感浮层 — 已锁定的赛道

统一质感语言：对角三段渐变底板 + 左上光斑 + 边缘提亮 + 柔和投影 + 渐变内容条； 差异在浮层的形态与细节叙事。V9 / V4 为首批样张。

SOFT · TOOLTIP

V9 气泡尾巴（质感）

速贴面板本体：tooltip 指向光标，两条渐变内容条 = 历史条目。16px 轮廓最整，语义最准。

SOFT · HOVER WAVES

V4 悬浮波（质感）

「浮」的直译：面板下方两道半透明悬浮波。元素最少、气质最轻盈。

SOFT · FADE LADDER

V12 渐隐浮梯

历史渐隐：面板下方两道渐淡的白条是「上浮时留下的旧条目」，剪贴板历史的层叠叙事。

GLASS · DARK

V13 深色玻璃

深夜磨砂浮窗：半透明玻璃面板 + 亮边描边 + 亮蓝内容条。七案中唯一深色底，与浅色系形成两极。

SOFT · CARET

V14 光标贴入

贴到光标处：面板内竖形光标 + 文本条，下方悬浮波。叙事最具体——「内容正贴进输入位」。

SOFT · DUO WINDOWS

V15 双浮窗

新旧两窗：半透明旧条目退居后方，实心新条目在前——「浮起最新一条」的层次感。

SOFT · GLOW ARC

V16 升起弧光

悬浮力场：面板下一道发光托弧（高斯模糊发光），比双波更凝练。
