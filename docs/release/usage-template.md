# FloatPaste {{version}} 使用说明

打包日期：{{date}}

## 启动方式

1. 解压 zip 包到任意本地目录。
2. 双击 `floatpaste.exe` 启动。
3. 首次启动后，应用会常驻系统托盘。

## 首次运行提示

- 当前版本没有代码签名，Windows 可能提示风险警告。
- 若系统阻止运行，请在确认来源可信后手动放行。
- 若无法启动，请到 `%APPDATA%\com.floatpaste\logs` 查看日志，并随反馈一并提供。

## 基本操作

1. 复制文本后，条目会自动入库。
2. 使用设置中的全局快捷键唤起速贴。
3. 使用方向键选择条目，按回车上屏；按 Esc 关闭速贴。自定义键位以设置和界面提示为准。
4. 从托盘菜单打开搜索窗口、设置或暂停监听。
