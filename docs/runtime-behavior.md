# 运行行为与数据约定

本文维护剪贴监听、搜索、上屏、跨窗口数据、自启提权和数据保留的当前行为。模块关系见 [架构概览](architecture.md)，窗口时序见 [无焦点速贴指南](no-focus-picker.md)。

## 剪贴监听与入库

- 三类条目：文本（原文/预览/搜索文本/来源应用/文本用途/可选 HTML）、图片（PNG 直传与 DIB、缩略图、哈希去重）、文件（路径列表/数量/总大小）。
- 文本条目按保守规则识别用途（整段链接 → Windows 绝对路径/UNC/逐行路径 → JSON 对象数组/完整围栏/多强特征裸代码，顺序即优先级），识别不确定时回到普通文本。用途只影响类型徽章、悬浮气泡与检索筛选，不改写原文、不访问磁盘与网络、不影响可上屏性；用户分类仍走标签。规则见 `services/text_kind.rs`。
- 链接识别校验 HTTP(S) scheme、主机标签、IP 字面量与 0–65535 端口；列表摘要突出主机与路径/查询/片段，不显示 userinfo。路径摘要突出首条路径的文件名与父路径，并标识额外路径数量。摘要最多 120 字符，悬浮气泡和上屏仍使用完整原文；代码气泡使用等宽字体并保留换行、缩进，度量与渲染共用字体。
- 同 hash（未删除）内容刷新既有条目并置顶，不重复插入。文本 hash 按原始 `full_text` 的 UTF-8 字节与可选 HTML 原载荷按固定顺序、格式标记和长度边界计算（带版本与基础类型前缀的版本化编码，见 `services/text_identity.rs`）：代码缩进、连续空格等原文差异是不同内容；空白折叠加小写的归一化文本仅用于搜索索引，不用于身份。文本用途不参与 hash，调整识别规则不会制造新条目；编辑保存文本后按同一规则重算用途与身份。图片、文件 hash 语义不变。
- 监听使用 `AddClipboardFormatListener`；暂停与来源应用排除先于解析。前台进程命中排除名单时先短路；读取快照时也检查剪贴板属主进程，来源元信息优先使用属主、不可得时回退前台进程。来源无法识别时不额外禁止采集，排除规则不承诺识别浏览器内的具体页面或插件。一轮复制在同一个 OpenClipboard 会话内收集受支持表示，释放后再解析/入库，入库前比较快照序列号与隐私状态代际，跳过过期结果。
- 文件优先；无文件时，CF_HTML 有可读选区文字则保存同一条目中的纯文本与 HTML，优先使用来源纯文本，缺失时仅从有效片段提取。纯图片 HTML 包装配有可读位图时走图片链路。HTML 损坏或超限时保留可用纯文本；没有可读文字或支持的位图时跳过。
- HTML 使用注册名 `HTML Format`、UTF-8 与字节偏移校验；单载荷最多 4 MiB，文字提取最多 1 MiB、50,000 个 token、128 层嵌套。监听先解析快照以选择录入分支，公开入库入口 `HistoryService::ingest_text_formats` 再次解析并筛除无可读文字、损坏或超限的 HTML；两处共用有界解析规则，当前尚未通过已校验载荷消除重复解析。超限回退纯文本；不执行脚本，不加载图片、样式或网络资源。HTML 原载荷仅用于本地存储与上屏，不承诺网页完整离线保存或跨应用显示一致。
- 上屏与恢复按主身份和实际纯文本/图片回退身份设置 3 秒抑制窗。
- 排除应用名单、暂停监听、自写回抑制（上屏写剪贴板不再入库）。

## 隐私边界与输入上限

- 快照先读取隐私标记，再复制正文：出现 `ExcludeClipboardContentFromMonitorProcessing`，或 `CanIncludeInClipboardHistory` 的 DWORD 值为 0 时，整条跳过，不以纯文本、HTML、图片或文件回退录入。只有 `CanUploadToCloudClipboard=0` 时仍可本地采集；历史许可为 1 不覆盖应用排除或暂停。不可读的标记返回错误，不按默认允许继续。恢复快照保留这些标记的历史/云同步语义，不能在恢复时解除来源的保护。
- 托盘和设置页的暂停立即保存，仅更新监听开关，不受其他设置草稿的快捷键冲突阻塞。暂停、恢复及锁屏状态转换都会使旧采集与上屏代际失效，并忽略转换时仍留在系统剪贴板的版本，不补采暂停/锁屏期间的内容。
- 剪贴板消息线程同时注册当前 Windows 会话通知；锁屏、控制台或远程会话断开时暂停采集与上屏，收起速贴、搜索、悬浮气泡及托盘菜单，释放速贴会话键与鼠标监控；不丢弃编辑窗口未保存的草稿。解锁不自动弹回面板。启动时查询当前会话；注册失败或无法确认会话状态时禁止采集/上屏，等待有效解锁通知或重启恢复。
- 文本正文上限 8 MiB（UTF-8），文件列表最多 1024 项、单路径最多 32,767 个 UTF-16 码元、路径 UTF-8 合计最多 8 MiB；监听与公开录入入口均检查，编辑正文同样检查文本上限。系统 Unicode 文本分配最多 16 MiB + 2 字节，单格式最多 256 MiB，整份快照最多 512 MiB，检查先于载荷复制。HTML 另沿用上方 4 MiB 上限及降级规则。资源超限不反复重试；瞬时剪贴板占用沿用短重试。
- 图片沿用共享单边 16,384 像素及 512 MiB 解码分配限制，RGBA 总量在像素分配前再次校验；图片存储读取 PNG 同样限制压缩体积与解码尺寸。图片清理仅接受 `images/<UUID>.png`，拒绝通过重解析图片目录删除文件。
- 默认日志不记录正文、搜索关键词、文件条目路径、窗口标题或 UIA 名称；定位敏感文本仍需显式 `FLOATPASTE_DIAGNOSTIC_LOG=1`，沿用[诊断说明](../CONTRIBUTING.md#调试与诊断)。这些保护不等于本地加密，也不能阻止同账号其他程序读取系统剪贴板。

## 搜索排序

- 查询结果按请求序号回写，新请求或会话重置会使旧响应失效；会话重置不将序号归零，避免重开后的首个请求与旧请求重号。丢弃旧响应不等于取消后台查询计算。
- `recent_desc`：`COALESCE(last_used_at, created_at) DESC`，再按 `created_at DESC`。
- `relevance_desc`：收藏与带标签条目加权置前，其次 `search_text` 子串命中，再按 FTS5 `bm25 ASC`，最后同 `recent_desc` 的时间序。
- 空关键词强制 `recent_desc`；收藏是独立筛选条件、不在速贴置顶，但在 `relevance_desc` 中有加权。
- 类型筛选「文本」下可再按用途细分（全部/普通/链接/代码/路径），细分 chip 仅在文本筛选激活时出现；「仅收藏」为独立开关，与类型、用途、关键词和标签按 AND 组合。切换收藏保留类型与用途，切出文本类型时清空用途；「全部类型」保留收藏开关，「清除筛选」同时清除类型、用途、收藏和标签。不选细分时「文本」包含全部用途。
- 操作按钮、动作目录与输入暂停提示显示当前配置的会话键，设置保存后即时更新；升级和冲突回退见[快捷键设置与升级](no-focus-picker.md#快捷键设置与升级)。无历史条目时根据监听状态引导复制或恢复监听。
- 速贴同样支持两段式删除，共用删除键位与删除服务；确认取消、列表选中与按钮布局见 [速贴单条删除](no-focus-picker.md#速贴单条删除)。

## 上屏执行

- 速贴与搜索选择动作、捕获各自会话，统一由 `paste_flow.rs` 执行：趁属主窗口存活写入剪贴板 → 调用来源窗口的隐藏流程 → 恢复目标窗口 → `SendInput` 注入 Ctrl+V；可选恢复原剪贴板内容。发布失败保留来源窗口以便重试；仅写剪贴板时不隐藏或注入。速贴保留目标控件焦点、返回搜索时恢复输入；搜索保留先还原目标再停屏的顺序。格式发布与序列号保护由 `services/paste_support.rs` 承担。
- 各窗口只选择主动作、次级动作或菜单临时动作，统一解析为 `PasteMode::Original / PlainText / PathText / FileNameText / ImageFile / TextFile / RevealInFolder`（动作目录与名称见 `domain/clip_item.rs`）。Enter 上屏本体，带 HTML 的文本同时发布 HTML 与纯文本；次级会话键执行该类别配置的默认变体——设置页按富文本、图片、文件分别配置，初始值沿用既有行为（富文本纯文本、图片与文件路径文本），普通文本次级等同主动作。搜索窗口使用左右拆分按钮：左侧「粘贴」始终执行主动作，右侧箭头打开「更多动作」，列出全部动作与快捷键；普通文本同样提供「更多动作」入口。速贴通过行内「⋯」打开更多操作菜单，上半部复用同款动作列表，临时选择不改变默认，也不修改条目。
- 「打开所在文件夹」（`RevealInFolder`，仅文件条目）不是剪贴板形态：发布链路显式拒绝该模式，`paste_flow` 在读取条目后前置分流——在资源管理器中定位条目引用的第一个仍存在的路径（多选跨目录没有单一所在目录），成功后收来源窗口、不恢复目标前台也不注入按键，且不更新条目使用时间（定位不算消费内容）；路径全部失效时提示「文件已被移动或删除」并保留来源窗口。根目录（盘符、UNC share 根）没有所在文件夹，直接打开该目录本身。定位优先复用已经显示该目录的资源管理器窗口（在其中选中目标并前置），无可复用窗口时才新开；多标签页窗口只按其活动标签页匹配，目标在后台标签页时视为未打开而新开（Win11 24H2 桌面取证确认）；COM 枚举失败同样回退新开，复用是优化路径而非承诺（`shell_open.rs`）。
- 动作目录：富文本（原格式 / 纯文本 / 粘贴为文件…）、图片（图片 / 图片路径 / 图片文件）、文件（文件 / 完整路径 / 文件名 / 打开所在文件夹）、普通文本（原文 / 粘贴为文件…，不重复提供「纯文本」）。图片文件把保存的 PNG 以文件列表（CF_HDROP）发布，目标应用按文件附件接收；文件名与完整路径同为逐行文本（CRLF 分隔）。速贴菜单的键盘路由与删除确认见[更多操作](no-focus-picker.md#速贴更多操作)。
- 「粘贴为文件…」（`TextFile`）仅作为文本菜单的临时动作，不加入默认次级设置；速贴与搜索共用命名窗口，默认 `文本.txt`，无扩展名时补 `.txt`。允许自定义 `.md`、`.py` 等扩展名，但只以 UTF-8 保存纯文本正文，保留换行、缩进和代码围栏，不自动转换、校验目标语法或执行内容。拒绝路径、控制字符、Windows 保留名称、尾部空格/点及超长文件名。命名时收起来源并释放其输入监控、保留目标会话；Esc、取消和关闭按钮返回原来源，生成或发布失败在命名窗口提示并保留重试。切换来源、锁屏或清除历史会关闭旧请求，隐私代际失效后的确认不得发布或恢复旧面板。确认后仍沿共享发布→恢复目标→注入链，文件以 CF_HDROP 发布并登记自写抑制；生成文件的保留与清理见下方[数据模型](#数据模型)。
- 设置页将三类默认次级动作放在独立分组中，组头显示当前次级会话键；选项使用简短形态名，每行说明随所选方式变化。快捷键页以「执行默认次级动作」命名该会话键，避免其含义被固定为纯文本或路径。
- 搜索的「更多动作」与速贴的「更多操作」均选中发起条目，编辑、收藏和删除快捷键作用于该条目。速贴菜单将上屏方式与管理操作分组，详情见 [速贴更多操作](no-focus-picker.md#速贴更多操作)。
- 多格式发布前准备全部载荷，在同一次 Open/Empty/Set/Close 会话内发布。中途失败尝试在持锁会话内恢复已准备的白名单快照，不注入 Ctrl+V；Win32 不保证数据库式原子发布。未能自动粘贴时通过托盘提示原因；开启恢复原剪贴板时引导重试，关闭时提示手动 Ctrl+V。
- 上屏操作具有固定操作 ID，发布、注入前判定与恢复判定通过共用串行门执行；归还目标与注入前检查本次版本，发布后重新持锁核验属主并读取关闭后的最终序列号，延迟等待不占锁。恢复等待 550ms，并在持有系统剪贴板锁后比较本次发布序列号；期间发生新复制或另一次发布时取消恢复。
- 发布、注入及延迟恢复还需核对隐私状态代际；锁屏、暂停/恢复监听或清除历史后，旧任务不得重新注入或恢复快照。隐私取消不提示上屏失败；注入前取消后不继续更新使用时间。已经写入系统剪贴板的内容不因此自动清空。
- 两来源的结果日志统一区分已注入、管理员目标仅发布、剪贴板变化取消、退出取消和失败。注入前持锁判定取消与错误，不在窗口层二次读取序列号推测原因；新复制取消不弹注入失败提示。活动时间保留既有尝试语义：恢复目标前取消不更新，进入后续尝试则更新（包括目标恢复失败或注入前最后核验发现新复制）；更新不表示目标应用确认接收。
- 快照只驻内存，捕获和恢复共用文件列表、Unicode 文本、HTML、PNG/DIB 白名单，可保留同次复制的多种表示；不承诺恢复任意应用私有格式。恢复需要的 HTML 超过 4 MiB 时，在写入条目前取消并提示，保留用户剪贴板。
- 管理员目标（UIPI）：目标窗口以管理员运行且本应用未提权时，按键注入会被静默丢弃。上屏前检测（`elevation.rs` TokenElevation），命中则照常写入剪贴板、还原目标焦点，仅跳过必然无效的注入；写入成功后经托盘气泡一次性说明（每进程一次，速贴/搜索窗口零 UI）。开启恢复原剪贴板时仅引导管理员重启，关闭时另提示手动 Ctrl+V。

## 跨窗口数据一致性

- 标签词汇与列表数据以「窗口打开/会话刷新时刻」为准，不做跨窗推送：设置页的标签改动在其他窗口下次打开或编辑后刷新时反映，不以事件总线同步。
- 设置窗标签区点击「条目数」跳转搜索窗是该原则下唯一的管理跨窗入口：预置该标签筛选（先与当前词汇求交集，标签已不存在则落到默认视图），首开与快捷键打开同一条上屏链、落地后顶边锚定收缩到内容高度（左上不动、底边伸缩）；会话已打开时直接切筛选、不隐藏重开。

## 开机自启与提权启动

- 提权是对一次性动作：设置页「以管理员身份重启」（未提权时显示）→ UAC 确认 → 经 `runas` 重启（新实例等旧实例释放单实例互斥量后接管）；重启后即拥有管理员权限。
- 任务计划程序是开机自启的唯一载体（`elevated_task.rs` COM ITaskService）：任务存在 = 「开机自启」开；任务 RunLevel（HIGHEST/LUA）= 「始终以管理员身份运行」开。该勾选仅提权运行时可更改；勾选后每次启动均带管理员权限——登录自启走 HIGHEST 任务免 UAC；手动启动（asInvoker manifest 不触发 UAC）由启动期自检兜底（`launch_mode::needs_elevated_relaunch`，托盘就绪后执行，透传 `--silent` 等原参数）。
- 启动期提权自检：预期提权而实际未提权时，经 UAC 重入自身（复用 `--elevated-relaunch` 闭环，本进程走退出收尾后让位，提权新实例接管）；UAC 被取消则本次以普通权限运行，托盘气泡说明一次。带 `--elevated-relaunch` 参数的启动不再自检，防 UAC 异常时无限弹窗。
- 任务 ACL 仅授予 SYSTEM/Administrators/任务所属用户：非提权进程可查询/删除/重建自己的任务，只有注册 HIGHEST 任务需要提权（进程已提权时直接注册；删除另有 `--remove-elevated-autostart` UAC 兜底）。启动时清理 Run 键中的本应用旧版自启条目，避免重复启动。
- 同步时机：启动时与设置保存后（后台线程串行执行，`query` 快照幂等跳过已达形态）；同步失败回滚对应开关并提示。触发器延迟 3s 等 Explorer 就绪；任务名带用户名避免多用户冲突。

## Win+V 接管

- Win+V 作为速贴的第二个唤起入口，与主快捷键执行相同动作；组合相同时跳过重复注册。
- 设置开关先弹出影响说明，用户确认后写入或清除 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\DisabledHotkeys` 的 V 字母并重启资源管理器；取消保持原配置。其他禁用字母保留，删空时删除整个值。
- 开启和关闭接管分别需要使资源管理器重启生效；不要求用户关闭系统剪贴板历史。`TaskbarCreated` 通知后延迟补注册，覆盖资源管理器恢复过程。
- 快捷键录制期间注销全局热键，避免录制组合触发本应用动作。卸载器清理接管的 V 字母并提示重启资源管理器。
- 实现见 [winv_takeover.rs](../crates/floatpaste-core/src/platform/windows/winv_takeover.rs)、[settings.rs](../crates/floatpaste-native/src/settings.rs) 和 [安装卸载脚本](../packaging/floatpaste.iss)；选型理由见 [ADR-0001](adr-0001-winv-takeover-via-registry.md)。

## 数据模型

数据目录统一为 `%APPDATA%\floatpaste`。首次启动且新目录不存在时，在打开日志、数据库之前把旧的 `%APPDATA%\com.floatpaste` 整目录重命名到新位置，保留数据库旁车、图片、设置与日志。新旧目录同时存在时使用新目录，不合并或覆盖旧目录；迁移失败时保留原目录并报告错误，不创建空库替代旧数据。`APPDATA` 缺失时仍使用当前目录下的 `.floatpaste-data`。旧版程序不会自动读取新目录；回退前先退出全部实例，备份并按旧版路径恢复所需数据。

SQLite（`%APPDATA%\floatpaste\floatpaste.db`）+ FTS5：`clip_items`（条目主表）、`clip_items_fts`（全文索引）、`settings`、`excluded_apps`、`tags`、`clip_item_tags`（条目-标签关联）、`clip_text_formats`（一对一 HTML 载荷）、`pending_image_deletions`（图片清理重试队列）。表结构与字段以 `repository` 的迁移与 `schema.rs` 为唯一来源，不在此复述。

存储策略：文本进库，只有带 HTML 的条目在 `clip_text_formats` 中有对应行；HTML 不进入 FTS，列表与普通详情只查询能力标记，上屏详情按需读取载荷。软删保留格式，物理删除通过外键级联清理。仅改标签、收藏或保存未改变的文本保留格式；保存正文修改时，在同一事务内删除 HTML、重算用途与 hash、更新摘要和 FTS。

图片以 PNG 存数据目录 `images/` 子目录；文件条目只记路径引用。文本上屏生成的附件存于 `text-files/<UUID>/<文件名>`，每次独立创建、不覆盖同名文件；发布失败尽力撤销本次文件，成功后保留七天供目标延迟读取或重复粘贴，到期随下述周期清理，退出不立即删除。缓存清理不递归、不跟随重解析点，不涉及用户源文件；缓存过期后剪贴板中的旧附件引用可能失效。删除为软删除：列表与搜索立即隐藏，行与图片载荷保留到保留清理物理回收，因此保留期内仍占磁盘；当前没有回收站界面。设置页「隐私」可配置普通删除保留天数（默认 30，0–365；0 表示下一轮清理回收）和未收藏历史保留天数（默认 0，不按时间清理，最多 3650 天）。后者按最近复制/粘贴时间清理，收藏豁免时间与数量上限；显式软删收藏仍到期回收。清理在启动延迟约 60 秒后及每 24 小时执行，不承诺恰好到期即删除。

行的物理删除与图片路径入重试队列同事务提交，文件删除成功或已不存在后才移除任务；失败时保留任务，在后续清理及重启后重试。文件条目清理不删除用户源文件。队列覆盖新发生的清理，不能追溯旧版已经遗失引用的孤儿图片，也不能补回旧版已删除的图片。

「清除全部历史」须在确认框再次确认，包含收藏、软删条目、HTML、全文索引、标签关联、应用图片和生成的文本附件；有编辑会话时要求先保存或放弃并关闭，避免丢失草稿。清除在后台执行，完成后结束速贴/搜索会话，清空窗口历史模型与图片缓存；图片或文本附件未清理完会明确提示重试数量；文本附件可重试清除全部历史，日常清理继续回收超过七天的缓存。设置、系统剪贴板及用户源文件保留；清除使旧上屏任务失效，并在当前进程中跳过当时的剪贴板版本。以后新复制仍正常采集，重启也沿用启动核对当前剪贴板的行为。此动作执行数据库压缩，但不承诺擦除备份、SSD 或其他磁盘残留。

v9 升级只新增图片清理队列；旧设置缺少保留期限字段时延续之前的默认行为。回退旧二进制不会消费队列，待回到支持版本后继续重试；回退期间新发生的清理不具备队列保护。旧版保存设置会丢弃不认识的保留期限字段，重新升级后缺失字段按默认值读取。

标签只经由条目关联成立：全量替换、重命名与物理删除路径上失去全部关联的标签行随之清理（孤儿清理）；仅被软删条目引用的标签保留——软删即保留期缓冲，清理不得改为 join `clip_items` 过滤，否则破坏恢复语义。

数据库升级时按保存的原文回填文本用途、列表摘要并重算文本 hash；v6 数据同样按当前规则刷新派生字段；v8 在事务内用运行时共用的格式身份函数更新文本 hash。不改 ID、标签与收藏，不合并历史条目；此前被旧版空白归一化合并掉的原文差异无法从库中还原。图片与文件行的用途列保持默认值并被忽略。

切回旧二进制前备份数据库；旧版编辑器不认识附加 HTML，不能保证旧版修改后的文字与格式一致。回退优先保留新数据读取能力，不通过降级删除用户载荷。
