# 编辑窗口行为规格

> 活文档：编辑窗口的现行交互规格与实现约束，随实现更新。选型决策与
> 被否方案见 [adr-0003](adr-0003-editor-window-redesign.md)。

## 工作区与常用操作

- 编辑窗口默认 800×600，最小 400×300。顶部 34px 工作栏左侧为标签和添加入口，右侧为撤销、重做、全选、换行、等宽和「整理」。正文占据剩余高度，底部状态栏显示来源、时间、行列字数以及保存和删除入口。
- 已选标签使用柔和底色区分，每项可直接移除；添加入口就近排列在标签末尾，保持交互邻近性。关闭标签浮层后，文本条目将焦点归还正文并保留光标与选区，非文本条目归还窗口级焦点。
- 正文使用不透明底色、15px 字号与 1.4 倍自然行高；面板以细描边界定，工作栏与正文用分隔线区分，不使用整圈焦点强调。保留空白区聚焦和 UTF-8 光标语义。
- 工具键可用 Tab 聚焦，再按 Enter 或空格执行。全选沿用 Slint TextInput，撤销和重做与正文键盘快捷键共用草稿历史。换行与字体只影响当前窗口的显示，不写入配置或正文。
- 默认自动换行；关闭后长行提供水平滚轮和可拖拽、可点击轨道的水平滚动条，光标移动时同步跟随。重新排版和内容变短时，两个方向的滚动偏移均收敛到有效范围。
- 标题栏在未保存文本时以主题强调色发光圆点徽标高亮提示；底栏右侧设有保存按钮（未修改时呈现轻量「✓ 已保存」微边框胶囊徽章，未保存时高亮为品牌蓝「保存」提交动作按钮）。保存操作通过「蓝点熄灭 + 按钮流转为已保存」提供零抖动的就地状态反馈，不再弹出顶部挤压正文的通知横幅。关闭使用标题栏或 Esc，未保存关闭确认维持原语义。图片与文件保持只读预览，不显示文本工具组与保存按钮，所有条目的删除入口均保留在状态栏最右侧。

## 文本整理

在文本条目中点击「整理」，或在正文按 Ctrl+Shift+T。菜单支持方向键、Enter 和 Esc。存在选区时仅处理选区，没有选区时处理全文。整理属于草稿编辑，每次结果变化可按一次 Ctrl+Z 撤销，按 Ctrl+Y 重做。保存并重新打开可看到整理结果，放弃修改后重新打开会读取上次保存的正文。整理后正文为空时可撤销，保存仍要求正文非空。

以下三个动作对同一输入 `"  甲  乙\r\n\r\n  丙\n\t丁  "` 的处理不同。

| 动作 | 结果 | 规则 |
| --- | --- | --- |
| 合并为单行 | `"甲  乙 丙 丁"` | 对多行文本去掉每行首尾空白与空行，以一个空格连接，保留行内间距 |
| 去除换行 | `"  甲  乙  丙\t丁  "` | 删除 CRLF、LF 或 CR，保留其他字符 |
| 修剪首尾空白 | `"甲  乙\r\n\r\n  丙\n\t丁"` | 去掉处理范围两端的空白，保留中间的换行和缩进 |

「合并 PowerShell 续行」适用于由反引号显式续行的简单 PowerShell 命令。只移除参数之间独立反引号及紧接的 CRLF 或 LF，保留原有空格、缩进、引号与参数内容，并去掉末尾一个行结束符。反引号后有空格、紧贴词尾，或换行在引号内时会保留草稿并提示。注释、here-string、停止解析标记和复合命令也会保留草稿。 [PowerShell 解析规则](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_parsing#handling-special-characters)

```powershell
Write-Output `
  '甲  乙' `
  "丙 丁"
```

结果为 `Write-Output   '甲  乙'   "丙 丁"`。

## 标签输入（多选面板）

- 标签更改立即保存，添加入口悬停提示自动保存；文本修改通过「保存文本」或 Ctrl+S 保存。关闭确认只处理未保存的文本，使用「继续编辑 / 放弃文本修改 / 保存并关闭」区分操作范围。
- 标签行只保留已选 chips（行内 × 删除，紧凑靠左）与固定「+」添加入口；整条标签行都是打开面板的点击目标，行内空白与行尾同样可点，点击落点不依赖 chips 的实际宽度（字体度量随环境变化）；添加/搜索/创建收敛到下拉面板——带放大镜图标的搜索框 +「已选标签」分组行（悬停胶囊式移除）+「推荐标签」分组建议区（带细分隔线，match / create / exists 三态）。
- 建议项采纳用 pointer-down 而非 pointer-up——浮层在 up 前消失会让点击落空。
- 面板交互：打开（点「+」或无标签时的引导文案）即聚焦搜索框；回车采纳高亮或按输入创建、Tab 补全、上下键导航（高亮行滚动跟随）、Backspace 空输入删末位；Esc 分层退出（有输入先清空、再按关闭面板，文本焦点回正文，非文本回窗口级）；点击面板外（搜索框失焦）即收起。
- 建议数据流：`EditorTagSuggestion`、`build_suggestions` 排除已选、空输入给常用标签。
- 常驻 + opacity 隐藏方案中**每一个可命中元素都必须门控**（`enabled` 绑开合态）：opacity 不隔离鼠标命中，隐形面板/输入框会拦截下层编辑区的点击。

## 富文本正文与格式

- 带 HTML 的文本仍使用纯文本编辑器；无需在底部常驻警告条打扰，保持纯文本视口纯净通透。
- 仅改标签、收藏、未改变正文的保存和放弃草稿均保留 HTML；正文实际修改并保存时，在同一数据库事务内移除格式并刷新用途、身份、摘要与 FTS，防止新文字配旧格式。
- 格式能力与载荷的存储、上屏与恢复约束见 [运行行为与数据约定](runtime-behavior.md)。

## 编辑区命中与自管滚动

- 换行模式下内容层铺满视口宽；关闭换行时按全文排版宽度展开并以 `x: -scroll-x` 平移。`TextInput` 内移留白，空白区点击由下层 `TouchArea` 承接——聚焦并把光标置尾。
- 滚轮滚动自管：内容层 `y: -scroll-y` 平移，`TouchArea.scroll-event` 即时应用（Windows 滚轮向下 `delta_y` 为负，`scroll-y -= delta_y`），上限 `max(0, 全文排版高 + 上下 padding - 视口高)`。
- **结构要点：`TouchArea` 必须是 `TextInput` 的祖先**——滚轮在 TextInput 忽略后沿父链冒泡，兄弟元素收不到；该 TouchArea 同时承接空白区点击。
- 置尾光标偏移按 **UTF-8 字节**传 `set-selection-offsets`（Slint 内置语义），Slint 侧无字节长度内建，由 Rust 维护 `draft-byte-len` 供给；用字符数会让中文光标落在字符中间。
- 光标移动及视口尺寸变化时按可见范围与留白校正水平、垂直滚动；载入条目时 `scroll-y` 复位，跟随逻辑自动把视口推到置尾光标处。
- 标签 chips 直接排列；标签与正文共享面板边界，工具栏分隔线界定输入区。面板卡片宿主（`note-surface`）自带不透明背景（`canvas-default`）与圆角（`border-radius: Metrics.radius-lg`）与微边框；正文与预览容器使用透明背景透出面板底色，既保证软件渲染器擦除光标闪烁时脏区有不透明底色可画，又避免子级直角矩形在底层圆角外侧溢出白色尖角。
- 通知/错误条：`height` 条件动画（`cond ? 36px : 0px` + `animate height` + `clip`），不能用 `visible`——Slint 布局引擎不读 visible，隐藏仍占位，会让下方 flex 区高度跳变。

## tooltip 与状态呈现

- 条目查询无结果时显示「未找到对应条目」；其他读取错误显示「条目加载失败」并提供「重新加载」。载入新会话或重试前清空旧文本草稿与编辑状态，防止把旧内容保存到其他条目。
- 静态提示锚点 = 按钮中心、气泡按自身宽度水平居中（左缘对齐在气泡宽于按钮时观感歪斜）。
- 气泡定位以**客户区原点**（`win32_ext::client_origin`）为宿主基准：`GetWindowRect` 含非客户区，带框窗口上按它对齐会偏移一个标题栏高度，叠加越界翻转后气泡完全脱离按钮。
- 未保存提示：标题栏强调色发光圆点徽标、底栏保存按钮动态切换「✓ 已保存 / 保存」状态与样式。
- 底栏显示「行 x，列 y · n 字」（1 起、列按字符数中英文同权），依赖 TextInput 未公开属性 `cursor-position_byte-offset` 回调 Rust 换算；`set-selection-offsets` 以 TriggerCallbacks 触发光标回调，载入置尾时行列与视口滚动自动同步。

## 已知绕行（上游依赖，标注移除条件）

- **首行文字上方白点**：非整数 DPI 缩放（125% 实测）下软件渲染器把光标条顶端画出 TextInput 元素几何 1-2px（parley 行盒顶高于元素顶），而增量重绘的脏区只认元素几何——越界段「画得上、擦不掉」，在光标列位上方残留孤立白点。100% 缩放整像素对齐不触发。绕过：TextInput 外包一层顶边与其重合的裁剪容器（`clip: true`），越界段在绘制管线直接被裁、不依赖底色；不要使用同色遮罩条，它与透明底不兼容；上游修复后可整体移除。
- **恢复时整帧重绘**：编辑窗口保持 Slint 侧存活，通过 Win32 可见性控制显隐。速贴与搜索共用打开路径：屏外加载内容，以 `DWMWA_CLOAK` 暂时遮住窗口，恢复 Win32 可见性并重挂材质，在最终位置请求完整重绘；等待 release 50ms / debug 200ms 后暖表面、解除遮罩并获取前台。屏外 `BitBlt` 不能保证完整客户区落到 DWM 表面，`warm_surface` 只提交当前缓冲，`force_full_repaint` 也只是异步请求；[DWM cloak](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute) 保留合成，让最终位置的首帧准备不暴露给用户。准备期提供布局与渲染机会，不保证 DWM 每帧均完成。关闭或重开须丢弃旧显示定时器，关闭先真隐藏、移回屏外，再解除遮罩；准备期关闭不覆盖已记忆的位置，退出时不再显露。遮罩或显露失败须记录错误并返回来源窗口。调整策略时须同时验证首次打开、关闭重开、主题切换及准备期取消；公共重绘边界见 [无焦点速贴指南](no-focus-picker.md#坑十四首帧重绘不能通过临时改变窗口尺寸触发)。

## 编辑体验基线

- Slint TextInput 处理 Ctrl+A/C/X/V、光标导航、选区、按词删除与 IME。草稿历史接收正文编辑结果，合并相邻连续输入和连续向前删除，将一次文本整理记录为独立步骤。新编辑清空重做记录，关闭或重新载入条目清空历史。
- 正文工具键有独立键盘焦点态；其他既有 TouchArea 按钮保持现行路径。高频动作可用 Ctrl+S 保存、Esc 关闭及 TextInput 原生编辑键位；标签面板继续支持全键盘操作。
- 图片预览 contain 缩略 + 右下角「打开」胶囊按钮交系统查看器细看；文件条目路径行点击用系统默认程序打开（hover 描边 + 文字提亮 + pointer 光标提示可点），统一走 `core::platform::windows::shell_open`。
- 明确不做：Insert 覆盖模式、文本自动保存（手动保存 + 脏确认是文本编辑设计）、图片滚轮缩放/拖拽平移（预览定位快速识别，「打开」承接细看）。
