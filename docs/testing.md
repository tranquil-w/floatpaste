# 测试体系

自动化测试分为单元测试和 L1–L3 集成测试，各层覆盖不同的风险面：

| 层 | 位置 | 覆盖目标 |
|----|------|----------|
| 单元 | 各模块 `#[cfg(test)]` | 纯函数与算法边界、错误路径、序列化兼容、平台二进制契约 |
| L1 进程内集成 | `floatpaste-core/tests/` | 临时库组装 `CoreState`，沿公共 API 串行验证连贯业务流（录入→去重→标签→收藏→搜索→软删→保留清理） |
| L2 无头 UI 驱动 | `floatpaste-native` 内联测试 | `set_size` + `dispatch_event` 驱动 Slint 窗口断言 UI 行为；winit 事件循环是进程级单例，此类测试必须单函数串行多段 |
| L3 真进程 E2E | `floatpaste-native/tests/e2e_smoke.rs` | spawn 真实二进制走完整用户链路，覆盖主要工作流；断言隔离库、窗口几何与前台归属 |

层间按失效风险分工：纯规则、解析和错误边界在最低稳定层验证；L1 经公开服务与真实临时存储检查资源契约；L2 检查界面与事件契约；L3 兜底主要工作流的进程接线。同一行为可在不同层检查不同风险，例如 L3 删除入口不能替代 L1 的图片载荷保留断言；避免在各层重复完整端到端链路。

运行命令见 [开发与贡献](../CONTRIBUTING.md)。单元测试就近放在模块内或所属 crate 的 `tests/`，测试名描述行为，如 `ingest_text_skips_self_write`。

图片保留由 L1 `image_retention` 经真实录入、软删和清理服务核对行与文件；HTML 格式的软删保留与级联回收由 `rich_text_lifecycle` 使用真实 HTML 载荷核对，图片用例不能代替格式契约。上屏序列变化的单元检查核对旧操作不触发注入且注入错误不被算作取消；真实焦点与按键注入仍需目标桌面验证。

发布流水线必须在解压便携包后、安装安装包后分别复用 L3 验证交付程序；安装、卸载、版本与哈希校验的执行入口见 [发布流程](release/process.md)。

## 缺陷复现与验收

回归断言优先验证用户可观察的结果和业务不变量，不将当前方案自动提升为契约。例如显示准备期应验证用户看不到未完成画面，不能据此要求所有窗口必须移到屏外；已明确的停屏、焦点、线程或资源释放约束仍须检查，机制断言应能指向相应契约。

闪烁、空壳、跳位等视觉时序缺陷，先用录屏或连续桌面采样捕获相关触发过程，再结合窗口状态、日志和渲染路径定位；不要仅因其他窗口有类似修复就套用等待时长或显示方案。记录复现条件、程序版本、主题与 DPI，以及采样覆盖的首次打开、关闭重开等实际场景；无法捕获时明确尚未复现，可继续检查静态路径与最小回归，但不以推测认定根因。修复后按相同条件对照，有限采样与自动测试通过不能证明 DWM 每一帧均正常。验证执行顺序与完整门槛统一见 [验证与交付](../CONTRIBUTING.md#验证与交付)。

## L2 无头驱动约束

- 入口唯一：各窗口契约段以 `pub(crate) fn run()` 提供并由单一 `#[test]`
  （`l2_headless_ui_contracts`）串行调用——Slint 平台绑定首个初始化它的
  线程，`#[test]` 各占一线程，多入口会抢占线程绑定而实例化失败
- 延迟显屏的正向断言须持续泵事件循环并在有界期限内检查实际几何，不能假定繁忙帧中多个定时器的等待可简单相加；提前显示与取消后的负向断言保留明确时序。
- 前台恢复契约的辅助窗口必须在首次 show 前移到屏外，并断言取得前台后位置不变；它们只提供真实 HWND 与焦点，不参与观感验收。静默装配契约须覆盖 show 前无 HWND 的延迟建窗路径，在再次装配前检查初始几何。速贴显屏契约仍在屏内验证真实落位、置顶和输入装配。
- 布局读数须在事件循环泵帧后取：无循环时布局 pass 不跑，行模型注入后
  `content-height` 等布局派生属性停留在旧值；不受布局影响的属性
  （如 Flickable 偏移）可直接赋值断言
- `changed` 回调由事件循环调度而非属性赋值时同步执行：断言其副作用须
  先泵一次循环（`run_event_loop_until_quit` + 定时线程 `quit_event_loop`，
  异步落地（`invoke_from_event_loop` 的闭包）同样只有循环运行时才消费）
- 查询链路用临时 SQLite 直写预置数据，不经系统剪贴板（互斥资源，
  见 L3 约束）
- 搜索契约段使用独占创建的临时目录，不复用仅按 PID 命名的残留库；编辑后刷新场景在同一 L2 入口内连续运行两次，核对跨段隔离，并验证过期分页失败不清除当前请求的加载态。查询请求的会话代际契约见 [运行行为](runtime-behavior.md#搜索排序)。
- 编辑窗口显屏契约复用编辑后刷新段的隔离库与窗口，检查准备期保持 DWM cloak、首次打开与切换主题后重开能够显露、准备期关闭和快速重开不会被旧回调弹回，且保留位置记忆并解除遮罩。`FLOATPASTE_UI_SNAPSHOTS=1` 额外输出 `editor-reveal-<明暗>-<帧号>.png` 的桌面合成采样，并检查静态标题文字已呈现；需要可抓屏的交互桌面，有限采样不能证明 DWM 每一帧均无闪烁。准备与取消约束见 [编辑窗口规格](editor-window.md#已知绕行上游依赖标注移除条件)。
- 全局快捷键与会话键迁移的单元契约覆盖一次性版本持久化、用户恢复旧键位，以及自定义会话键／全局键与迁移目标冲突时整组保留。L2 在已有行模型上修改主／次级、编辑、收藏、删除与取消键，验证速贴顶栏、管理菜单、搜索按钮的真实悬浮提示、缓存动作目录及编辑窗口入口键帽同步更新。
- 设置窗口 L2 验证速贴、搜索和会话快捷键的多行错误提示均撑高行卡；启用 `FLOATPASTE_UI_SNAPSHOTS=1` 输出最小窗口宽度下的深浅主题快照 `shortcut-errors-<明暗>-<缩放>.png`，检查输入框及提示不被裁切。
- 富文本的单元契约覆盖中文/emoji 的 CF_HTML 字节偏移、实体与非可读节点、损坏与解析上限；L1 覆盖格式感知去重、v7 升级、正文编辑去格式、标签保留与软删/物理清理。系统剪贴板契约放入同一 L3 串行资源范围，覆盖 HTML 采集、缺失纯文本回退、超限降级与恢复拒绝、重读、原格式/纯文本发布、回退身份抑制、多格式/文件快照恢复及新复制取消延迟恢复；驱动进程的自写 guard 断言不能代替真实应用上屏的跨进程验收。
- 文本用途覆盖多行中文/emoji 的识别与旧库迁移；URL 识别覆盖无效 IP、端口和 authority。搜索窗口验证「仅收藏」与类型、用途组合，以及组合视图中取消收藏的即时移除。「更多动作」的动作目录投影与两个菜单的键盘路由、开合由 L2 契约覆盖（`action_menu_tests` / `action_sheet_tests`）；指针事件验证选中与未选中行的更多入口只开菜单，Delete 键事件验证跨行打开搜索菜单后的选中与删除待确认状态。真实发布（含图片文件 CF_HDROP、文件名文本）属系统剪贴板契约，随 L3 串行资源验证。
- 速贴延迟显示契约在同一入口调用 `picker::reveal_contract_tests::run`，
  用受控延迟的准备结果检查界面响应、任务并发上限、超时回退和关闭后丢弃结果；
  覆盖范围与连续帧观感的验证边界见 [窗口指南](no-focus-picker.md#坑十四首帧重绘不能通过临时改变窗口尺寸触发)。
  前台段依赖可控交互桌面，无法取得前台时打印跳过原因，须单独报告覆盖缺失。
- 速贴等高卡片契约在 `picker::action_sheet_tests` 中通过实际指针命中区域测量行高，覆盖短文本、多行中文与 emoji、空预览、长标签及来源、收藏、选中、缩略图回填和窄窗口，并核对非默认「速贴卡片高度」档的行高与预览行数预算跟随变化；标签摘要数量与长文本省略号同步断言。
- 同一契约覆盖普通文本的更多入口与行点击隔离、菜单收藏及再次打开后的状态、管理项的实际键位、失活守卫、Esc 分层取消、切换条目/重新打开菜单/刷新取消确认、超时解除与延迟回调时的时限校验，以及删除中间项、末项与删空后的选中状态；窄矮窗口检查删除高亮自动滚入视口并可点击，越界菜单项不得回退为上屏。`FLOATPASTE_UI_SNAPSHOTS=1` 额外输出更多菜单常规与删除待确认的深浅主题快照（`picker-more-<明暗>-<确认态>-<缩放>.png`），等高快照覆盖 280/360px 宽、长内容、图片及菜单确认态（`picker-equal-height-<宽度>-<明暗>-menu-<缩放>.png`），选中但未悬停的常态快照将 `-menu` 换为 `-idle`；截图前泵事件循环等待颜色动画结束。真进程 E2E 覆盖首次触发保留、再次确认软删与面板保持打开。
- 悬浮气泡契约由同一入口调用 `tooltip::headless_contract_tests::run`，覆盖同目标移动不延后显示、显示后位置稳定、切换与取消、预热期间会话失效、长文本与中文/emoji 的有界排版、文件详情的名称/父目录层级与数量、最近活动文案、图片属性与等比缩放及失败清空旧图；图片尺寸覆盖 8×8 小图放大、普通图原尺寸与极细长图的非零边界。纯函数测试覆盖路径拆分（含盘符根目录与 UNC）及负坐标工作区的翻转与四边约束。设置 `FLOATPASTE_UI_SNAPSHOTS=1` 生成短文本、代码、长单行、文件列表、大量文件、长目录、图片、长来源、8×8 小图、图片失败与按钮提示的深浅主题快照，使用 `SLINT_SCALE_FACTOR=1` / `1.25` / `1.5` 检查三档缩放。

## L3 端到端约束

### 隔离

被测实例的全部状态必须圈在临时目录内，靠以下钩子实现（缺省会走生产行为，钩子仅测试使用）：

- `APPDATA=<临时目录>`：进程级环境变量重定向，数据库、图片存储、日志随之整体隔离
- 预置设置须清空 `excluded_apps` 等默认过滤项：录入断言的采集来源进程取决于运行宿主（CI 的测试进程由终端拉起、前台即终端，而终端在默认排除表内），不清空会让 marker 被静默过滤、录入链路在 CI 上必失败
- `FLOATPASTE_INSTANCE_ID`（仅字母数字与连字符）：给单实例互斥量与唤醒事件名追加后缀，被测实例与日常实例共存
- `FLOATPASTE_RETENTION_FIRST_DELAY_MS`：覆盖保留清理首轮延迟（默认 60s），让接线验证落在测试时间尺度
- `FLOATPASTE_SKIP_AUTOSTART_SYNC=1`：跳过自启同步——它操作真实系统的 Run 键与任务计划，不随 APPDATA 隔离
- `FLOATPASTE_E2E_KEEP=1`（诊断用）：保留临时目录（实例日志在 `floatpaste/logs`），供间歇失败的事后取证；默认清理
- `FLOATPASTE_E2E_EXE=<程序绝对路径>`：指定交付程序作为全部启动与二次唤醒的目标；缺省使用 Cargo 提供的测试构建
- `FLOATPASTE_E2E_STRICT=1`：日常 CI 与发布门禁禁止因剪贴板不可用而跳过整个 E2E，环境不满足时必须失败；焦点段按下方交互桌面约束单独报告覆盖情况

### 驱动与断言

- 外部驱动只走真实用户路径：写系统剪贴板触发录入、二次启动进程经唤醒事件开关速贴面板；不使用键盘注入（SendInput 在安全软件环境不可靠）。真实快捷键分发、上屏注入、第三方应用兼容性与视觉效果不属于此冒烟测试覆盖范围，涉及这些行为的改动按需在交互桌面验证，不作为每版固定人工发布关卡
- 托盘菜单命令与键盘动作经命名事件驱动（当前驱动绕过模态菜单点击和按键注入；新增事件须触发与真实入口相同的处理终点，仅绕过分发层；均仅 `FLOATPASTE_INSTANCE_ID` 设置时装载）：
  - `signal_test_toggle_monitoring` — 托盘「切换监听」
  - `signal_test_open_search` — 托盘「打开搜索」
  - `signal_test_search_escape` — 搜索窗 Esc 关闭（key-close 回调）
  - `signal_test_picker_favorite` — 速贴收藏切换（toggle_favorite）
  - `signal_test_picker_delete` — 速贴两段式删除（handle_session_action）
  - `signal_test_search_delete` — 搜索窗两段式删除（request_delete）
- 键盘动作的到达前提是会话活跃（与真实按键的 FocusScope 前提对齐），驱动前须确认对应窗口已激活
- 速贴面板显隐是「屏内 ↔ 屏外停屏（-32000 平移）」语义而非 `SW_HIDE`，`IsWindowVisible` 恒真——面板开合断言必须看窗口几何（`GetWindowRect` 左上角是否在屏内）；未打开设置的冷启动还须连续采样 `WS_EX_TOPMOST`，确认置顶状态能跨越异步样式重排保持稳定，避免屏内几何掩盖窗口被遮挡的问题
- 窗口查询同时限定被测子进程 PID、标题、可见性与屏内位置，避免日常实例或同场景的其他实例干扰断言。
- 停屏浮层装配闪现守卫：启动到首次主动打开速贴前，后台线程采样主实例 PID 下业务窗口的可见性和位置（含速贴、搜索、悬浮气泡、托盘菜单及默认标题的编辑/设置窗），均不得屏内可见；首次打开前收口，避免把合法悬浮气泡误判为启动闪现。它检查 `silent_assemble_*` 的「show 前先停屏」顺序，不能保证捕获 DWM 的每一帧（见 [无焦点速贴](no-focus-picker.md) 坑十）。
- 键盘动作前等数据落地：窗口落位先于异步列表加载（fetch_next），此时行缓存为空、动作会静默返回；**高度收缩到结果高度 = 数据已入库渲染**，以此作为几何侧的就绪信号
- 两段式删除的两次触发必须都落在待确认窗口（3s）内且期间无选中变化（选中切换会解除待确认态）
- 速贴定位预置 `LastPosition` 模式与屏内记忆位置：Mouse/Caret 模式依赖运行环境的光标与前台窗口，E2E 验证的是唤醒链路而非定位模式
- 搜索窗几何断言（顶边锚定）用独立第二实例：矮数据集保证「起步满高 → 落地收缩」必然发生；顶边基准用与被测实例同源的 `center_in_work_area` 复算「满高起步的居中 top」——直接对比窗口两次读数会在首读已收缩完成时漏检重居中回归；光标读取被拒（输入桌面不可达）时与应用同样退回主屏工作区复算基准，单屏下逐位一致；双实例并存时存在同标题停屏搜索窗，且 winit 预建的隐藏窗口自进程启动起就停在级联默认位——枚举必须按「屏内 + `IsWindowVisible`」过滤，否则会赛跑赢过应用自身的装配落位
- 前台归属断言（Esc 还原）依赖「打开时前台是确定目标」：测试进程在屏外创建真实可见顶层窗口并以 `AttachThreadInput` 手法取得前台（复用被测实例同款 `force_foreground_window`），避免辅助窗干扰桌面；**目标窗口的消息必须被泵出**（前台转移经跨线程消息往返异步落地，忙轮询不泵消息会让激活永不落地、随后被停屏清空成 NULL 前台）——轮询闭包内对目标窗口执行消息泵；无人值守会话（无交互前台，`GetForegroundWindow` 为空）拿不到则焦点段整段跳过——焦点语义只能在交互桌面验证

### 卫生纪律

- 单测试函数串行推进：系统剪贴板、全局热键、速贴窗口都是会话级全局资源
- 子进程回收必须用 Drop 守卫覆盖 panic unwind 路径：孤儿被测实例可能持有外层管道句柄，使整条测试命令无法结束
- 被测实例收尾走优雅退出（`signal_test_exit` 命名事件 → 正常收尾路径），超时才兜底强杀：避免进程退出时遗留剪贴板占用或无效的数据句柄，影响后续读取
- 剪贴板是互斥资源，输入法、剪贴板管理器等外部进程会间歇占用，写入类操作短重试，持续失败让测试失败（不掩盖环境故障）
- 预置数据的活动时间戳以 1ms 步进保证严格单调：排序并列时（同毫秒入库）「最新条目」的选中/删除目标不确定
- 运行副作用：被测实例短暂占用主/搜索快捷键组合、读写系统剪贴板（结束时尽力恢复受支持格式快照）

### 富文本交互兼容性

### 失败排查

间歇失败仍须按失败处理，先保留证据，再区分应用回归、测试驱动竞态与环境问题。

1. 设置 `FLOATPASTE_E2E_KEEP=1` 保留隔离目录，记录失败提交、命令、宿主会话和失败断言；对齐驱动发出、实例收到事件与断言超时的日志时刻。
2. 按下表检查剪贴板和交互桌面的状态；某项异常只能证明对应条件不满足，不能据此排除其他回归。
3. 对照相同环境下的基线提交。使用独立工作树或先妥善保存改动，避免为排查覆盖工作区；基线也失败只能说明问题可能共有，仍需比较日志与环境证据。
4. 完成取证后再恢复环境，复跑失败用例；需要时复跑完整测试。恢复后通过不能单独证明最初失败的原因。

| 症状 | 检查与判定 | 处理 |
|------|------------|------|
| `OpenClipboard` 持续 `ERROR_ACCESS_DENIED` | 检查是否持续占用、持有窗口和应用日志；可能涉及外部进程或被测实例 | 排除持续占用；普通前置探测可跳过，CI 与发布严格模式必须失败 |
| `CF_HDROP` 数据读取报句柄无效 | 保留剪贴板格式与读取错误日志，区分启动核对和后续监听是否正常 | 不能仅凭该错误认定某进程崩溃或认为它导致录入超时；取证后重新复制有效内容并复查 |
| `GetForegroundWindow()` 为空 | 检查无人值守、锁屏或断连会话，确认没有可用的交互前台 | 焦点段按驱动约定跳过并报告覆盖缺失，主业务段继续；交互桌面补验焦点行为 |
| 复制 marker 后未入库 | 核对写入是否成功、监听是否收到通知、来源过滤、自写回抑制及入库错误 | 沿链路定位失败点，不直接归因于剪贴板坏态 |

### 剪贴板持续不可用时的恢复

先尝试正常退出确认占用剪贴板的应用；确认 shell 组件相关且常规退出无效时，再考虑重启资源管理器或注销重登。执行前保存当前工作、说明影响；不要把结束 shell 进程当作测试或重跑的固定前置步骤。

测试前置探测和运行中失败的处理边界：

- `clipboard_unusable_before_start` 在启动前约 1.2 秒内无法打开剪贴板时，普通模式打印提示并跳过；严格模式必须失败，禁止空跑发布。
- 运行中写入短重试后仍失败则报错，保留现场；失败可能来自实例行为或环境变化，不得跳过掩盖。
- 系统剪贴板和全局快捷键属于共享资源，复现时避免并发运行其他 E2E；单跑仍可能失败，应按同一流程排查。
