# 原生复刻迁移路线图

> **给代理执行者：** 按阶段顺序推进；每阶段以 `src/`（前端行为规格）与 `src-tauri/`（服务行为规格）为唯一对照来源，凡与旧版行为不一致，以旧版为准（除非用户明确要求变更）。每阶段收尾须保持 `./scripts/win-cargo test` 与 `./scripts/win-pnpm build` 全绿，并独立提交（中文提交信息）。所有步骤使用 `- [ ]` 复选框跟踪。

**目标：** 以 `crates/floatpaste-native`（Slint 软件渲染）完整复刻 FloatPaste 全部用户可见行为，消除 WebView2 内存开销；复刻验收通过后删除 `src/` 与 `src-tauri/`。

**复用基座：** 速贴面板与悬浮气泡已在原生壳中提供，沉淀了三类可复用资产——`ui/picker.slint` 的 `ClipRowCard`/`ListScrollBar`/`ResizeHandle` 组件、`PanelGeometry` 几何单一来源模式、`overlay` 模块的浮层样式与前台策略。新窗口应优先复用，不另起炉灶。

---

## 阶段零：速贴链路人工验收

- [ ] 悬浮气泡：Alt+Q 唤出速贴后悬停条目，确认气泡内容、延迟、位置、点击穿透符合旧版（参照 `docs/superpowers/specs/2026-03-31-tooltip-window-design.md`）
- [ ] 前台归还：唤出速贴后焦点始终留在目标窗口；数字键、Esc、双击粘贴、点击外部关闭逐项过一遍
- [ ] 缩略图条目与长文本条目（含入库截断的 URL）预览裁排无行高抖动
- [ ] 窗口边缘九向缩放、位置记忆（`picker_last_position`）与旧版一致

**验收标准：** 与旧版并排操作无可感知差异；发现偏差按对照规格修正后重验。

## 阶段一：搜索窗口复刻（旧版 `src/features/search`，约 1900 行）

- [ ] 窗口骨架：780×420、可缩放、位置/尺寸记忆、无边框浮层样式（走 `overlay`）
- [ ] 搜索框与过滤下拉：关键词即时过滤、类型筛选、标签筛选（对照 `2026-04-04-search-filter-dropdown` 系列 spec）
- [ ] 结果列表：复用 `ClipRowCard`/`ListScrollBar`；删除条目后即时从列表缓存移除
- [ ] 内联展开布局、图片预览与悬浮气泡（对照 `2026-04-05-search-inline-expansion-layout`、`2026-04-05-search-image-tooltip-delay`）
- [ ] 条目操作：复制、粘贴到目标窗口、进入编辑、收藏、标签管理、删除（事件语义对照 `src-tauri` 的 search_service 与 events）
- [ ] 快捷键会话：搜索窗口内的导航/确认/取消键位与旧版 `ShortcutManager` 的会话规则一致

**验收标准：** 以旧版同数据源并排对比搜索、筛选、展开、操作全链路；列表滚动与选中跟随无跳动。

## 阶段二：编辑器窗口复刻（旧版 `src/features/editor`，约 1060 行）

- [ ] 窗口骨架：800×600，从速贴/搜索以"当前项编辑"进入，会话事件对照 `floatpaste-core::domain::editor_session`
- [ ] 纯文本编辑：加载、保存、脏状态、未保存关闭确认
- [ ] 键盘语义：Enter/方向键回归文本编辑，Esc 取消；标签建议浮层
- [ ] 保存后联动：速贴与搜索列表的对应条目即时刷新

**验收标准：** 对照 `2026-03-21-editor-window-design.md` 逐节核对；未保存确认与来源窗口返回行为与旧版一致。

## 阶段三：设置窗口复刻（旧版 `src/features/settings`，约 1830 行）

- [ ] 窗口骨架：920×760，常规窗口（非浮层），标题"FloatPaste · 设置"
- [ ] 主题设置：明暗跟随、预设（Catppuccin/Primer/暖中性等）、自定义强调色（对照主题系列 spec 与 `theme_bridge` 现有令牌）
- [ ] 行为设置：数字快捷键开关、悬浮气泡开关与延迟、粘贴执行方式（对照 `settings_service` 与 `floatpaste-core::domain::settings` 的 sanitized 规则）
- [ ] 排除应用、保留策略、数据目录/图片存储管理
- [ ] 快捷键自定义：录入、冲突提示、注册失败的用户可见反馈
- [ ] 开机自启开关；托盘菜单入口

**验收标准：** 每项设置修改后立即生效并持久化；重启应用后配置还原；主题切换即时作用于所有已建窗口。

## 阶段四：系统能力对齐

- [ ] 托盘：图标（含 DPI 取档）、菜单项与行为对照 `src-tauri/src/services/tray_service.rs`
- [ ] 开机自启：对齐旧版注册方式与取消行为（服务逻辑在 `floatpaste-core::services::startup_service`）
- [ ] 单实例：二次启动唤醒已有实例并唤出速贴
- [ ] 退出流程：停输入拦截、剪贴板监听、热键，再落退出标志（对齐 `main.rs` 现有收尾顺序）
- [ ] 打包与安装：确定原生壳的安装包产出方式，版本号、图标、卸载行为对齐旧版

**验收标准：** 从安装到卸载的全流程与旧版用户可见行为一致；托盘/自启/单实例在重启后稳定。

- [ ] 性能对照：空载/常驻内存与 WebView2 版对比，确认收益达成
- [ ] 验收通过后删除 `src/` 与 `src-tauri/`，`AGENTS.md` 目录说明收敛为 `crates/` 单树结构
