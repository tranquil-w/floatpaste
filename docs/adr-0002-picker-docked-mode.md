# 速贴固定显示与停靠形态

速贴此前只有热键唤出的弹窗形态，且窗口生命周期敏感（TOPMOST 与 search 窗口耦合，惰性建窗改造曾整体回退）。决定为速贴新增「固定显示」模式：托盘菜单开关，开启后常驻可见；拖至屏幕任意边缘即吸附为停靠，鼠标离开收为细条，悬停约 300ms 或点击细条展开，热键照常可用；停靠状态持久化，重启可恢复。速贴窗口内不加任何按钮。

## Considered Options

- **仅"钉住不外击关闭"模式**：拒绝。用户要求完整的停靠交互（吸附、缩条、展开）。
- **独立新窗口承载停靠形态**：待 spike 结论。若常驻单窗路线吃性能回归，再评估缩条与面板两窗两段式（参照此前动态建窗两段式经验）。

## Consequences

- 硬约束：不回退既有内存优化成果（PNG 透传、页缓存收紧、SLINT_DESTROY_WINDOW_ON_HIDE）；实施前先做 spike 验证常驻窗口 + 缩条 + 展开在 winit + Slint 软件渲染下的性能与生命周期路线，spike 结论补充进本 ADR。
- 现行基线为五窗启动即建：速贴/搜索/悬浮气泡 winit 窗口常驻（显隐走屏外停屏，不调 `hide()`），编辑/设置窗关闭即销毁回收帧缓冲、两段式重建；「惰性首建」改造曾整体回退。
- 退出固定显示走托盘菜单同入口，退出后恢复弹窗形态。
